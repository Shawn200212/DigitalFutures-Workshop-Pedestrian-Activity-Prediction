# 2D / 3D 离线直达入口说明

这个文件夹是完整离线网页，不需要 Python、Conda、Node，也不需要重新训练模型。

## 推荐打开方式

- 双击 `打开模型可视化网页.bat`：进入完整交互网页。
- 双击 `index.html`：进入完整交互网页。
- 双击 `open_3d.html`：直接进入 3D 沉浸视图。
- 双击 `open_hotspot_3d.html`：直接进入热点 3D 视图。
- 双击 `open_residual_2d.html`：直接进入残差诊断视图。

## 可复制的直达链接

如果网页已经打开，可以在地址后加：

- `#3d`：连续预测强度的 3D 沉浸视图。
- `#hotspot`：y >= 5 热点概率的 3D 视图。
- `#residual`：仅标签节点的残差诊断视图。

例如：

```text
index.html#3d
index.html#hotspot
index.html#residual
```

## 迁移注意事项

迁移到其他电脑时，请保持整个文件夹结构不变，尤其不要把 `data/app_data.js` 单独移走。该文件包含 46,607 个节点的模型预测、标签、误差、分类结果和变量影响信息，是网页离线运行的核心数据。
