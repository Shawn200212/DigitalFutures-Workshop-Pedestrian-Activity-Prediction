# 离线 GraphSAGE 结果浏览器

[English](README.md) | **中文**

这是上海街道行人活动强度 GraphSAGE 模型的离线可视化网页。

## 快速打开

双击 `打开模型可视化网页.bat`，或直接打开 `index.html`。

## 文件不要拆开

- `index.html`
- `app.js`
- `styles.css`
- `data/app_data.js`
- `打开模型可视化网页.bat`
- `模型可视化网页使用与视频制作文档.md`

## 主要功能

- 2D 俯视空间预测图
- 3D 沉浸式模型结果浏览
- 连续预测、真实标签、残差、绝对误差、热点分数和热点分类图层
- split 与 tile 筛选
- 节点悬停详情
- 变量组和单变量影响展示
- PNG 截图导出
- 视频制作镜头预设

## 离线迁移

将整个文件夹复制到其他电脑，或解压随附 ZIP 后双击启动器即可使用。无需安装 Python、Conda、
Node 或任何模型依赖。
