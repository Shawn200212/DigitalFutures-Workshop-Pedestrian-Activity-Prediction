# GraphSAGE 模型可视化网页使用与视频制作文档

## 1. 网页用途

本网页用于展示上海街道行人活动强度 GraphSAGE 模型结果。它是一个纯本地静态网页，不需要重新训练模型，不依赖外部网站，也不需要联网。

当前接入的数据来自：

- 最佳固定 split 回归模型：`outputs/gnn/full_retrain_best_20260703/fixed_split_champion`
- 训练后阈值校准分类结果：`binary_y3`、`binary_y5`、三分类
- 5-fold 泛化评估结果：`outputs/gnn/full_retrain_best_20260703/kfold_best`
- 特征影响分析：`feature_importance`

网页入口：

`index.html`

数据文件：

`data/app_data.js`

## 2. 打开方式

### 推荐方式：双击打开

双击：

`打开模型可视化网页.bat`

或者直接双击：

`index.html`

### 备用方式：本地服务器

如果某台电脑的浏览器限制本地文件读取，可以在网页目录中运行：

```powershell
py -m http.server 8765 --bind 127.0.0.1
```

然后访问：

`http://127.0.0.1:8765`

## 3. 网页布局

网页由三部分组成：

- 左侧控制栏：视角模式、图层、split、tile、点大小、3D 高度、色阶、视频镜头按钮。
- 中部主画布：2D 俯视图或 3D 沉浸图。
- 右侧分析栏：节点详情、变量组影响、单变量影响、tile 误差排行。

## 4. 视角模式

### 2D 俯视

适合展示：

- 城市空间预测分布
- 热点平面图
- 残差平面图
- tile 对比

操作：

- 鼠标滚轮：缩放
- 鼠标拖拽：平移
- 悬停节点：查看预测值、真实值、残差和热点分数

### 3D 沉浸

适合展示：

- 预测强度的立体峰值
- 热点区域的空间起伏
- 视频中的动态漫游镜头

操作：

- 鼠标拖拽：旋转视角
- 鼠标滚轮：缩放
- `3D 自动环绕`：自动旋转视角
- `3D 高度`：调整柱状高度/起伏强度

建议：

- 展示连续预测时用 `连续预测强度 + 3D 沉浸`。
- 展示热点时用 `y >= 5 热点分数 + 3D 沉浸`。
- 如果画面过密，把点大小调低到 1.6-2.2。

## 5. 图层说明

| 图层 | 含义 | 推荐用途 |
| --- | --- | --- |
| 连续预测强度 | 模型回归输出的人流强度 | 主展示图 |
| 真实标签强度 | 有标签节点的真实值 | 对比真实观测 |
| 残差 | 预测值 - 真实值 | 诊断高估/低估 |
| 绝对误差 | abs(预测值 - 真实值) | 查找误差高区域 |
| y >= 5 热点分数 | 高人流热点分数 | 高强度热点展示 |
| y >= 3 中高分数 | 中高人流分数 | 候选活跃区筛查 |
| y >= 5 分类 | 高人流二分类 | 明确热点边界 |
| y >= 3 分类 | 中高人流二分类 | 更宽松的活跃区展示 |

## 6. 筛选控件

### Split

- `Train`：训练 tile
- `Val`：验证 tile
- `Test`：测试 tile

建议：

- 汇报模型效果时只保留 `Test`。
- 展示全城预测时保留 `Train + Val + Test`。

### Tile

选择单个 tile 可以做局部案例展示。

建议流程：

1. 先看全部 tile 的总体趋势。
2. 再选择误差排行中 RMSE 较高或较低的 tile。
3. 切换预测、真实、残差图层做局部解释。

### 仅标签节点

用于只显示有真实标签的节点。

建议：

- 看 `真实标签强度`、`残差`、`绝对误差` 时打开。
- 看全城预测和热点分数时关闭。

### 仅热点预测

用于只显示预测为热点的节点。

建议：

- 在 `y >= 5 热点分数` 或 `y >= 5 分类` 下使用。

## 7. 视频制作推荐流程

左侧有五个视频镜头按钮：

1. 预测总览
2. 3D 沉浸
3. 热点分布
4. 残差诊断
5. 变量影响

建议按以下顺序录制：

### 镜头 1：预测总览

操作：

1. 点击 `1 预测总览`。
2. 保持 `2D 俯视`。
3. 图层为 `连续预测强度`。
4. 保持全部 tile。

讲述：

模型输出的是连续行人活动强度，用于表达城市街道空间中的活动强弱。

### 镜头 2：3D 沉浸

操作：

1. 点击 `2 3D 沉浸`。
2. 打开 `3D 自动环绕`。
3. 根据画面调节 `3D 高度`。

讲述：

高度代表当前图层的强度，越高说明模型预测的人流活动强度越高。

### 镜头 3：热点分布

操作：

1. 点击 `3 热点分布`。
2. 使用 `y >= 5 热点分数`。
3. 可切换到 `y >= 5 分类`。
4. 可勾选 `仅热点预测`。

讲述：

模型训练阶段保持连续回归，热点结果是在训练后通过验证集阈值校准得到的。

### 镜头 4：残差诊断

操作：

1. 点击 `4 残差诊断`。
2. 只保留 `Test` split。
3. 开启 `仅标签节点`。

讲述：

残差图显示模型在哪些位置高估或低估。高人流极值仍容易被低估，因此后处理阈值校准很重要。

### 镜头 5：变量影响

操作：

1. 点击 `5 变量影响`。
2. 查看右侧 `变量组影响` 和 `单变量影响`。

讲述：

模型最依赖 50m 建成环境，其次是 800m 网络结构和 200m 建成环境。人口变量相关性强，但在模型中部分影响被建成环境和网络结构吸收。

## 8. 导出图片

点击 `导出 PNG` 可以保存当前画布。

导出前建议确认：

- 当前视角是 2D 还是 3D
- 图层是否正确
- 是否只显示 Test
- 是否选择了具体 tile
- 点大小和色阶是否合适

## 9. 离线迁移说明

迁移到其他电脑时，只需要整个文件夹完整保留：

`GraphSAGE_行人强度可视化_便携版`

文件夹中必须包含：

- `index.html`
- `app.js`
- `styles.css`
- `data/app_data.js`
- `打开模型可视化网页.bat`
- 使用说明文档

迁移后打开：

1. 解压 zip。
2. 进入文件夹。
3. 双击 `打开模型可视化网页.bat`。

不需要安装 Python、Node、Conda 或任何模型依赖。

## 10. 常见问题

### 网页打开后没有图

检查 `data/app_data.js` 是否还在 `data` 文件夹内。不能只复制 `index.html`。

### 中文显示异常

优先用 Chrome、Edge 或 Firefox 打开。网页已声明 UTF-8 编码。

### 3D 画面太密

把点大小调低，或者只显示 `Test` split，也可以选择单个 tile。

### 3D 高度太夸张

把 `3D 高度` 调低到 0.8-1.2。

### 想更新成新的模型结果

在原项目中重新运行：

```powershell
& 'C:\Program Files (x86)\miniconda3\envs\svi_ped\python.exe' scripts\gnn\build_model_viz_app_data.py --run-dir outputs\gnn\full_retrain_best_20260703\fixed_split_champion --kfold-dir outputs\gnn\full_retrain_best_20260703\kfold_best --output-dir outputs\gnn\model_visualization_app_20260703\data
```

然后重新打包网页文件夹。
